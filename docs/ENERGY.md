# 能耗与后台更新

AgentKib 使用缓存展示发现结果、会话用量和额度。缓存过期表示数据可能不够新，不等于必须立即启动后台任务。

## 默认行为

| 场景 | 本地发现与统计 | 额度（已开启自动获取时） |
| --- | --- | --- |
| 主窗口可见且未最小化 | 发现每 15 分钟、统计每 30 分钟检查更新 | 至少间隔 5 分钟 |
| 最小化或隐藏到托盘 | 暂停自动更新 | 至少间隔 15 分钟 |
| 系统休眠或锁屏 | 暂停调度 | 暂停调度 |

仅切换到其他应用不暂停更新。恢复系统或重新显示窗口后等待 2 秒，合并检查到期任务，不补跑错过的周期。已经开始的任务允许完成。

设置中的“自动更新本地发现与统计”默认开启。关闭后可手动刷新；首次使用没有缓存时，只在前台初始化一次，失败后需要手动重试。额度使用独立的“自动获取额度”开关，保留用户已有选择。

额度采集没有任何有效结果时保留上次成功数据，按 5、15、30、60 分钟退避，后台同时遵守 15 分钟最短间隔。重启保留退避状态；显式强制刷新可以提前尝试，但不会重复启动同类在途采集。隐藏额度展示不改变采集配置。

## 统计缓存

Codex 日志逐文件保存检查点：未变文件只检查元数据，正常追加只读取新增完整行。末尾半行留到下一轮；截断、替换或解析版本变化只重建受影响文件。SQLite 模型与估算数据单独缓存，保持详细日志优先的统计规则。

来源贡献、游标和受影响日期汇总在同一数据库事务中更新。读写失败保留上次有效结果；只有目录枚举成功才移除已消失来源。工作区新增、删除及模型归类变化可以重新归类缓存，不需重读全部日志。

数据库版本 14 新增内部检查点和来源关联，版本 15 将检查点拆为逐来源记录；已存在的版本 14 检查点会在成功刷新时原子转换，不重读未变化日志。升级后先显示原有统计，首次成功采集后切换；初始化失败不会清空旧数据。缓存只包含加盐来源标识、文件元数据、必要解析状态和标准化用量，不保存对话正文、凭据或明文来源路径。

## 远程功能

远程面板共享可见性轮询，无连接、共享或配对活动时不做周期查询。相同结果保留原状态引用。窗口隐藏只暂停界面查询，不停止已启用的 Web 服务。

Web 订阅按会话及权限范围合并正在执行的读取，每个客户端仍独立验证授权。相同快照不重复发送，15 秒心跳维持连接。LAN 相关的 30 秒地址检查改动依赖尚未提交的 LAN 功能，暂留本地工作区。

## 验证方式

歷史固定資料集曾以 Rust 測試和隔離 benchmark harness 驗證未變檔案的讀取量、SQLite 寫入量，以及前景／背景執行個體的 CPU 和磁碟 I/O。Rust-only harness 已隨 Rust backend 一併移除；這些舊命令不再適用於目前版本，也沒有 TypeScript 等價的長時間能耗 benchmark。

目前可用的 macOS 開發版啟動與畫面檢查方式：

```sh
pnpm typecheck
pnpm --filter @agentkib/desktop electron:build
pnpm dev
```

在開發版檢查視窗隱藏／顯示、系統休眠恢復及閒置期間是否仍持續掃描。此手動檢查不能取代量化能耗採樣；不要執行已移除的 `benchmark-energy.mjs` 或 Cargo 命令。
