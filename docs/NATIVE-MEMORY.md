# Claude Code 原生记忆只读接入

桌面的「资源库 → 记忆」汇总已发现工作区的 Claude Code 项目自动记忆。工作区无需托管。`MEMORY.md` 和同目录 Markdown 专题文件可以查看、搜索；同一真实目录只索引一次，保留全部关联工作区。

这是文件预览，不是当前会话上下文的确认。Claude 启动时的 `MEMORY.md` 读取限制为前 200 行或 25 KB，专题文件按需读取，见 [Claude 官方说明](https://code.claude.com/docs/en/memory)。AgentKib 的预览有独立上限。

## 按项目浏览

记忆页按项目分组列出有内容的记忆；空来源不占用文件列表。列表仅显示文件名，不展开正文标题、摘要和修改时间。共享同一真实记忆目录的多个工作区合并展示，并可查看关联工作区。

宽窗口采用列表与正文双栏，各自独立滚动；选择记忆后在右侧阅读正文，可切换预览与原始文本。窄窗口使用详情抽屉，返回列表时保留浏览状态。搜索与来源筛选继续同时适用于原生文件和 AgentKib 记录，原有提议审核入口保留。

“来源与诊断”默认折叠，展开后查看配置、来源状态与读取限制。异常、缓存过期和扫描不完整只在项目行及汇总处提示，不将正常或空来源逐项铺满主界面。原生正文仍为只读预览，选择或查看不代表当前 Claude 会话已加载。

## 来源与安全边界

- 使用现有 Claude 配置解析，包括应用进程环境中的 `CLAUDE_CONFIG_DIR`、自动记忆开关、用户／managed 自定义目录及主仓库／worktree 共享规则。
- 项目／local 设置指定自定义目录、但工作区信任状态不可确定时，显示路径无法确定。不会读取该外部目录或将默认目录冒充为有效来源。
- 不反推无法归属的历史目录。不包含 `CLAUDE.md`、rules 或子代理独立记忆。逐会话命令行覆盖不在配置可见范围内。
- 只接受有效记忆目录中的 Markdown 文件。目录内安全符号链接可读，越界、网络、设备、敏感路径和跨设备目标不可读。不加载远程资源，不跟随外部引用。
- 不写入原生文件，不写入已有 `memories` 表。原有提议、审核和 Agent 检索语义保持不变。原生正文不开放给 MCP、远控网页或其他 Agent。

## 缓存与更新

独立的本机 SQLite 表 `native_memory_cache` 保存脱敏后的有界正文及文件版本。新增表兼容现有 schema 15；缓存是可丢弃的投影，原生文件仍为权威来源。

页面先显示缓存，后台独立扫描。页面可见时观察文件变化，并每 5 秒合并核对；进入、回前台、手动刷新也会核对。macOS 使用文件通知和目录元数据观察，避免关闭多个目录事件监听时阻塞。离开页面、窗口隐藏、导航或渲染进程退出会撤销观察。

普通 IO／权限失败保留上次正文并标记过期。确认删除或文件变为不安全目标后撤下旧文件；排除工作区、关闭自动记忆或切换配置来源后撤下旧来源。旧扫描和迟到详情不能恢复已撤下内容。

| 限制                   | 上限                           |
| ---------------------- | ------------------------------ |
| 每个记忆目录的文件遍历 | 512 个文件                     |
| 子目录深度             | 4 层                           |
| 单文件读取             | 512 KiB                        |
| 单文件预览             | 沿用 `FILE_CHARS` 文本长度限制 |
| 每目录正文索引         | 8 MiB                          |
| 列表单页               | 100 项                         |
| 搜索单次返回           | 50 项                          |

触及限制时显示扫描不完整或预览截断，不将未覆盖部分当作空结果。搜索对文件名和脱敏正文进行空白分词后的 AND 子串匹配，不依赖语言分词器。

## 本地接口

以下方法通过现有本地 runtime 和可信桌面 IPC 调用，不增加 Web 路由或 MCP 工具：

| Runtime 方法             | 参数                                              | 结果                             |
| ------------------------ | ------------------------------------------------- | -------------------------------- |
| `memories.nativeList`    | 可选 `workspaceId`、`sourceId`、`query`、`offset` | 来源、文件元数据、分页及刷新状态 |
| `memories.nativeSearch`  | 同上，`query` 为关键词                            | 搜索快照                         |
| `memories.nativeRead`    | `{fileId}`                                        | 只读正文、来源和同目录引用 ID    |
| `memories.nativeRefresh` | `{}`                                              | 重新核对后的快照                 |
| `memories.nativeObserve` | `{active}`                                        | 启停桌面观察                     |

详情仅接受索引签发的文件 ID，不接受路径。列表和详情分别缓存；来源切换清理旧详情，普通刷新保留当前预览。`memories.nativeChanged` 事件使桌面查询失效并读取更新结果。
