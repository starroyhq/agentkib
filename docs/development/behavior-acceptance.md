# 用户行为验收表

用这张表回答「某功能支持吗」。先看适用的 Agent、运行方式和最近一次实测，再回答已验证的范围。每个结果只对应所列版本、环境和证据。产品修复合并后，拿同一路径实测并更新该行。

- **通过**指所列路径已经验证。**部分通过**指只验证了其中的环境或步骤。**失败**指最近一次相关实测出现了表内所述偏差。**待验**指缺少该路径的验收证据。预期置灰、只读或拒绝的行为也能验收通过。
- 「真包」指安装包实际运行过的行为。「原生回环」指隔离宿主或 CLI 使用合成会话及回环模型。「现场」只记录已知现象，保留当时版本不明的情况。「已合并」只标记待复验的修复。
- 负责人是发现偏差时的首个联系人。a 负责验收与发版，b 负责目录、历史、已读、组件库和手机构建，c 负责项目 Agent、续跑及 Codex，d 负责安全、设备、账号、中继、附件与权限，e 负责 Claude Code 接入。界面偏差由验收记录交主控分派前端修复。
- 第一版共 50 行。基线是 0.36.2 正式发布与候选包（[构建](https://github.com/starroyhq/agentkib/actions/runs/45978416131)），另记第二轮 U52 预检与 PA-5 的源码提交。待复验修复截至 c40078314。

## 读者、账号与设备

A01、A16、A17、D05 各跑两套独立数据。使用隔离的 HOME、AgentKib 数据目录、浏览器、回环端口和测试工作区；挂接本机模型时使用回环假模型及测试凭据。每套先新建一条有未读结果的会话。

1. 不登录 AgentKib 账号，核对宿主读者范围为 `local`；需要双端时使用同一隔离宿主的局域网配对。
2. 登录独立测试账号，核对宿主读者范围为 `account:<测试账号 ID>`。包括账号已登录而官方中继未启用的桌面路径。双端走同一宿主的授权浏览器或设备。
3. 每次读、手动标记或撤销前后，用只读方式查询隔离数据目录的 `codex-managed/executions.sqlite`。用托管 Claude 测 AgentKib 已读。按账本 `key`（Agent、原生 HOME 和会话 ID 的哈希）与 `reader_scope` 查 `conversation_read_cursors`，用同一 `key` 关联 `conversation_read_sources.latest_id` 到 `conversation_read_results.result_id`。确认阅读后 `read_sequence` 应覆盖已看到的非基线结果，`manual_unread` 为 0。标为未读后，相应标记须落账，另一范围的记录保持原状。测试使用原生已读状态的 Codex 时，核对原生确认。切换到 AgentKib 已读状态时再核对对应范围的游标。
4. 双端验证同一宿主、同一读者范围的状态传播；撤销后重复读取与标记，核对请求被拒且游标不变。记录版本、匿名的范围类别、前后游标/标记及实际设备结果。报告只保留合成 ID、状态及计数。

### 在本机重跑 AT01

在 Apple 芯片主机上用 Node.js 22 或更新版本，从独立工作树准备依赖并打包。

```sh
pnpm install --frozen-lockfile
pnpm --filter @agentkib/desktop build:electron
CSC_IDENTITY_AUTO_DISCOVERY=false pnpm --filter @agentkib/desktop exec electron-builder \
  --mac --arm64 --dir --publish never -c.mac.identity=null
node .github/scripts/run-desktop-acceptance.mjs \
  apps/desktop/release-electron/mac-arm64/AgentKib.app/Contents/MacOS/AgentKib
```

命令也接受该提交的其他独立解包副本。追加 `local`、`account` 或 `legacy` 可单跑对应场景。三个场景各自使用临时 HOME、运行数据、Electron profile 和回环端口，依次启动。登录场景由同版本 Electron 用 mock keychain 生成合成缓存，应用使用正常的账号恢复路径。旧桥接场景向隔离宿主的真实 Claude 桥发送 0.5.12 形状的事件，并追加合成原生记录。

AT01 先核对侧栏的未读点和合成会话的终态，再点击打开并滚到实际最后一条回复，核对未读点消失、当前读者游标写入 SQLite、其他读者范围无写入。切走再回来时核对结果仍保持。进程退出后清除该场景的临时文件。

需要安装包人工操作或真机的行先每天跑一次，重大版本前补未完成的行。记录版本、运行方式、账号状态、结果及可复核证据。发现偏差时按负责列交接。发版按[轻量流程](release.md)，全量验收安排在 1.0.0 前。
