# 持续集成

- 兼容检查和额度采集器验收按 PR 的变更路径触发。同一个 PR 的新运行会取消旧运行。定时检查、手动运行和发布调用各自独立。
- Codex 协议检查在 Ubuntu 上运行，继续用官方 CLI 的最低支持版和最新版生成并校验 app-server schema。CLI 在断网、根文件系统只读的容器里执行，只能挂载本次的临时目录和 CLI 文件。脚本在 macOS 本地仍使用系统沙盒。
- Claude 终端兼容检查继续在 macOS 上运行最低版和最新版，验证系统沙盒的隔离行为。额度采集器 PR 仍校验所有目标，发布时仍构建并验收每个目标的产物。
- [主质量工作流](../../.github/workflows/ci.yml)继续在 main 上执行全套检查，包含架构门禁。[桌面发布工作流](release.md)继续执行原有的原生构建、校验、签名和发布步骤。
