# 会话形状采集

此探针供维护者核对 Claude Code 会话的落盘状态。它按一个会话采集，生成供审核的结构报告。先把探针交给主控审阅，再由主控决定是否在用户数据上运行。

在包含本地 `designs/` 的检出中，使用仓库要求的 Node.js 版本。给出 AgentKib 数据目录、AgentKib 会话 ID 和对应的 Claude JSONL 转录。示例中的路径及 ID 都是占位符。

```sh
node /path/to/worktree/qa/probes/capture-session-shape.mjs \
  --data-dir /path/to/agentkib-data \
  --session-id EXAMPLE-SESSION-ID \
  --transcript /path/to/native-session.jsonl
```

探针用 macOS 的 `sandbox-exec` 运行采集子进程，禁止文件写入和联网。它只打开显式指定的转录及固定的 AgentKib 落盘文件。SQLite 使用只读事务，不启动 AgentKib 或 Claude，不复制数据库。父进程只接收结构报告，创建一个权限为 `0600` 的 `designs/shapes/session-shape-*.json` 文件。捕获有 15 秒的上限，失败时只打印固定的错误文字。

每份报告包含：

- 托管记录的生命周期标记、末轮状态，以及结束结果是否指向同一轮。
- 回执的阶段和白名单操作类型、宿主队列形状、编排计数、存在于账本里的读者范围类别和数量。
- 落盘桥接绑定的撤销和在途标记。桥接的当前租约属于进程内状态，报告标为 `not-observed`。
- SQLite 会话索引和工作区表的行数。两个会话索引可能有重叠，不能相加当作去重后的会话数。
- 转录尾部的记录类型和顺序、白名单字段的存在性和类型、报告内的局部引用序号。转录最多读取 8 MiB，最多投影 1,024 条完整行，单行超过 4 MiB 时只计入跳过数量。内容块最多每条 64 个、共 2,048 个，优先保留较新的记录。

数据来源独立读取。每个 SQLite 文件各有自己的只读快照，无法把数据库、JSON 文件与持续追加的转录视为同一事务。源不存在时报告标为 `missing`，系统拒绝读取、格式不符合或超过该源限制时标为 `unavailable`。例如 WAL 所需的共享内存文件不存在且 SQLite 试图创建它，沙盒会拒绝，探针不会补建。报告中的读取范围、跳过条数和截尾标记可用于区分缺失证据和观察到的空集合。

输出仅包含固定字段、已知枚举、布尔状态、结构计数和报告内的引用序号。正文、标题、路径、工具参数、令牌、账号标识及原始标识不输出。新增的枚举值和字段名需先经过审核，未知的值不会原样进入报告。

`designs/` 已被 Git 忽略。只在本机把采集结果交给主控审核。仓库里的回放夹具应以报告为参考单独构造，使用全新 ID、路径和内容。
