# 会话状态契约 v1

后台的 `deriveSessionState` 将同一会话的事实整理成一个结论。目录、详情、设置和指派应使用同一结论。生产者先从 Claude 的执行租约、托管记录、原生轮次、回执和编排登记取得事实，再交给函数。函数是纯函数，只读取传入事实。首批提交只建立契约、推导和测试，后续接线时再向客户端声明能力。

## 状态与权限

- `execution` 描述写入归属及证据。断开的桥接、过期租约、保留的绑定、未知的原生进程各有不同含义。确认没有写入者才用 `none`。校验失败用 `unknown`。托管 runner 回收后，已核验的托管归属仍可为 `agentkib`。
- `turn` 描述原生轮次，等待审批和提问分别使用 `awaiting-approval` 和 `awaiting-answer`。原生完成可使轮次为 `idle`，旧插件补发结束事件前，普通发送仍可因 `awaiting-send-ack` 暂停。发送和停止都有独立的写入路径。只有确定会收到对应写入路径的更新时，才声明 `control-readiness` 自动恢复。`controls.send` 只管普通发送，插话和排队继续使用各自的门禁。
- `controls` 给出当前授权范围内的设置、发送、停止、指派和接管。接管可用必须由原生准入独立核实，包括写入租约、在途输入、已投递的汇报及原生控件占用。Provider 是否声明能力决定能否提供操作。设备权限和工作区范围仍在入口重新核验。指派时还要核验选定的负责人、候选会话和工作区组合。项目 Agent 工具是否准备好是独立事实。
- 被禁用的操作带有固定原因和恢复状态。有可调用的操作就给操作、有已知会推进的信号就给自动恢复、当前会话和调用方没有可行路径时明确标为 `terminal`。审批、提问、核对和接管只有当前调用方确实能操作时才成为解法。核对只验证原执行结果，`retry` 只重新读取状态。
- 编排登记或已读读取失败时分别使用 `role.kind: "unknown"`、`read.status: "unknown"`。状态无需携带命令 ID、原生路径、原始回执或设备授权材料。

## 未确认回执

`unknownCommands` 只汇总仍需保护的回执。已核对退役、但无法确认原结果的回执仍可在原回执查询中返回未知。`knowledge: "unknown"` 表示账本读不到。`unclassified` 表示实际查到回执，但无法确定它改变了什么。两种情况都会暂停写入，直至取得相应证据。

| 未确认的操作 | 暂停的控制 |
| --- | --- |
| `send`，包括已经派发的插话和队列输入 | 普通发送、指派、接管 |
| `stop` | 停止、接管 |
| `settings` | 设置 |
| `takeover` | 发送、停止、设置、指派、接管 |
| `other`，已知不影响上述控制 | 无 |
| `unclassified`，无法判断影响 | 发送、停止、设置、指派、接管 |

真实轮次结果不明时，还需要轮次自身的证明。例如已核验接管完成、原生记录确证这轮已经结束且没有在途输入，此时一条遗留的设置回执只挡设置。若原生轮次也不明，恢复路径必须覆盖该轮以及当前操作涉及的回执。手动核对和已确认会送达的回执更新可以分工。旧投影里的通用 `outcome-unknown` 不能直接用作原生轮次证据。

## 接线与验收

1. Claude 适配层先统一详情、目录、设置和指派的事实。执行归属复用后台现有的归属核验，回执结论来自按操作分类后的账本。只有当前调用方有权读取的结论可进投影。主机在实际下发 `live.state` 后才在 `access` 声明 `sessionStateVersion: 1`。该字段和状态对象都按能力协商，协议主版本沿用现值。
2. HTTP 快照、SSE 快照及增量共享授权投影。消费者按会话、宿主运行代和可见权限范围接受整份状态，避免迟到的快照覆盖更新的结论。`version` 是结构版本。生产者在同一发布范围内为状态变化推进 `revision`。断开、重启或授权换代时重建该范围的版本基线。
3. 桌面与 Web 从共享 `session-ui` 迁移 `session-display-state.ts`、`use-session-controller.ts`、`session-composer.tsx`。优先收拢 Claude 的模型与权限选择、审批和交接面板、目录行和托盘的归属判断。独立的 `SessionWorkerAssignmentDialog.tsx` 使用宿主返回的候选结论。终端原生模型菜单仍有自己的可用条件，常规设置状态不能推导出该菜单可打开。
4. 手机把协商字段接入 `packages/agentkib_client/lib/src/models.dart` 的 `Access`，用生成的 `SessionState.tryParse` 读取快照和增量。迁移 `LiveState.isTerminalClaude`、`ConversationController.canSend/canStop`、`conversation_controls.dart` 和 `conversation_status.dart`，同步核对设置、提问卡和接管入口。远端只展示授权投影给出的实际操作。
5. 旧宿主、尚未接线的 Provider 或不受支持的版本由兼容适配读取既有字段。已协商的 v1 始终使用它的结论，包括 `unknown` 和 `disabled`。应下发 v1 却缺失或解析失败时，视为状态不可用，并重新获取状态。用同一个案例核对宿主准入、目录、详情、发消息及指派，包含设置孤儿回执、重启和旧插件结束事件迟到。界面上的核对入口继续使用现有按钮文案。
