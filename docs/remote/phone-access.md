# 手机访问、Codex 远控与产物查看

这条链路在电脑上的 AgentKib 内运行。关闭手机页面不会停止任务；桌面应选择关闭窗口后保留后台运行。完全退出 AgentKib、休眠或关机会使远程服务不可用，没有安装系统守护进程。

## 桌面设置

1. 打开“设置 → 远程连接”，在“手机”卡片点“连接手机”。引导窗口一次只显示当前这一步：没登录时先在浏览器中登录；登录后自动开启远程访问（登记电脑、准备安全连接、连接），不用再点“开启”；准备好后直接显示二维码和授权码。旧官方地址的迁移、设备被撤销后的重新登记和自建服务的邀请码仍要在窗口里明确点一次。没能开启时窗口说明原因和下次自动重试的时间，也可以“现在重试”。使用 [AgentKib Remote 托管连接](account-relay.md) 时通过已登录账号登记电脑，无需邀请码；电脑和手机须登录同一账号，并另行完成八位码配对。默认管理 API 为 `https://api.agentkib.com`，安装包内置 frpc，证书私钥和 CSR 在本机生成。
2. 二维码旁选择这台手机能做什么：“完整控制”或“只读”，换档位会换一个对应档位的授权码，再由手机扫码并输入。默认仍为完整控制；授权码按两组显示，位数和五分钟有效期不变，过期后点“重新生成”。验证成功即进入 AgentKib，无需回电脑确认或逐项勾选权限；窗口随即显示这台手机已连接，可以“再连一台”。
3. **分享授权码即授予所选档位权限**：“只读”可查看会话历史与文件；“完整控制”还包括全部已登记及以后新增工作区的任务控制、审批和问答，以及电脑上已支持的附件、队列、会话整理和设置。授权码五分钟有效，成功使用一次即失效；仅交给可信设备。
4. Codex 的原生审批、执行策略、版本兼容、原 ID 与工作区核验、原生写锁及未知结果阻断保持有效。同 Agent 续接不需要用户勾选交接；完整授权不等于自动批准命令，也不开放尚未支持的工作树或 Git 分支操作。
5. 已配对的旧浏览器保留原有逐项权限、实验开关和选定工作区范围，不自动升级。需要完整访问时，撤销旧设备并用新授权码重新连接。工作区之外的额外只读目录仍由桌面显式添加；普通远控不能读取任意绝对路径。
6. 完成设置后，“手机”卡片写明状态（已开启、已暂停、正在连接或连接中断）、设备数和本月中继用量，用到 80% 起变成提醒；下面是已授权浏览器列表，可调整档位、确认撤销或“连接新手机”（直接到扫码那一步）。暂停远程访问在卡片右上角的“…”菜单里，要确认；暂停后主要按钮换成“恢复”，沿用已保存的连接服务和程序路径，不应用高级设置中的未保存草稿。暂停、完全退出应用和撤销浏览器含义不同，都不等于终止 Codex 后台任务。账号配额、两步验证、归属处理与退出在“…”菜单的“账号”里。
7. 手机 App 登录了 AgentKib 账号、电脑也登录同一账号时，配对绑定到手机的这次登录，浏览器列表里注明“跟随手机的账号登录”。这次登录结束（手机退出账号，或在账号里被撤销、过期、改密码、用恢复码），电脑在几分钟内收回这台手机的授权；电脑换登别的账号时也一样。手机上保留这台电脑的记录，重新输入授权码即可恢复。登录期间授权自动续期，不再满 30 天就要重新输码。账号只能让电脑收回授权，不能授予授权；电脑未登录或登录的是别的账号时不绑定，配对仍按 30 天有效。

登录恢复不会被当作退出：Electron 与手机在安全存储保留账号快照和刷新恢复记录，重启先复用未过期凭据，断网或响应丢失时保留身份并提示恢复。支持 `refreshRecovery:true` 的账号服务接受同一 `refreshRequestId` 取回已提交的最近一次轮换；旧服务的未知轮换不能盲目重复，只能重新登录。同账号经验证的新登录可续接仍有效的配对，跨账号、明确退出或撤销仍结束旧授权。业务写请求不因修复登录而自动重发；代理 HTML 401 和普通 403 不构成撤销证明。须先升级后端，再更新客户端，旧后端回退可能令待恢复轮换失效。

新版桌面可读取旧的加密 refresh token 文件；写入后的版本化加密记录包含恢复状态，旧桌面不支持读取，降级需要重新登录。显式退出会先保存退出标记，删除凭据失败也不能在重启后自动恢复登录；新登录成功保存后才解除标记。

“高级设置”是单独的窗口，只有一个“保存”：连接服务（官方，或自建时的服务地址、按需的邀请码、frpc 程序和预览带宽）、共用的局域网网卡和手机局域网端口，以及“更多设置”里的本机 Web 服务、额外只读目录等。“取消”丢弃窗口里没保存的修改。只有实际改过的子系统才会提交；修改手机局域网配置会撤销该服务的浏览器授权，未修改时不会因保存其他项而撤销。两套局域网连接仍有各自端口、凭据和权限，不会因为共享网卡选择而互相授权。

本机 Web 与局域网配置保存期间共享操作状态，关闭弹窗不会结束仍在处理的保存，也不能通过另一个入口交错提交。写入失败后，重新打开设置或刷新状态不代表配置已经保存；需明确重试并成功保存，才能把相应网络配置用于电脑共享。本机名称在“其他电脑”的配对码旁点铅笔修改，失去焦点或按回车时独立保存，成功后短暂提示“已保存”；失败保留草稿供重试，不由高级设置的“保存”提交。

连接服务地址和自定义 frpc 路径也由高级设置的“保存”应用：先保存本机 Web 与网络设置，成功后再应用连接服务。官方服务的首次登记和重新登记均使用已登录账号；邀请码入口仅在高级设置中为自建或旧服务保留兼容。更换服务需确认并清除原浏览器授权；自定义程序保留原 SHA-256 校验。已有未归属官方设备须登录并认领，手动 HTTPS 访问入口保留。

`https://remote.agentkib.com` 保留为托管网页入口与 LAN 可信 Origin；它不是上述 API 地址。同网段的 [局域网直连](hosted-web-lan.md) 是单独启用的次级入口；桌面 [连接其他电脑](desktop-connections.md) 属于原生只读连接，和手机访问分别配对。

中继的程序连接成功不等于可访问。证书、域名或外网探测未通过时，不展示可用二维码。断开中继会恢复本地预览地址；变更服务配置会使旧预览票据失效。

旧官方 broker `https://remote.agentkib.com` 和此前开发配置 `https://api.remote.agentkib.com` 不会自动迁移。用户需明确选择 `https://api.agentkib.com`，登录账号后完成新地址的设备登记，无需邀请码；不复制旧地址的登记、pending 文件或凭证，普通重连不会改变已有地址。

登记请求的结果未确认时，保留已落盘的 pending、请求 ID 和凭证，恢复同一登记；账号登记须使用原账号，不删除 pending 或换请求 ID 重试。旧版匿名登记的未知结果也不会自动改为当前账号的新登记。

设备被撤销后普通重连仍会拒绝；官方服务须登录设备所属账号并点击「重新登记设备」，才建立新身份，无需邀请码。自建服务按其要求在高级设置填写新邀请码。重新登记成功前保留原登记文件；本次登记结果未确认时仍恢复同一请求。

控制和预览分别使用独立 frpc 进程及 TLS 连接。每 20 秒刷新一次最长 60 秒的授权租约；明确撤销立即关闭公网 sockets，后端失联后租约到期也关闭。休眠唤醒先重新授权。这会暂停远控访问，但不会自动终止 Codex 后台执行。该机制针对正常 AgentKib，不承诺服务端能强制踢掉恶意修改客户端的全部旧连接。

证书提前 21 天续期，临时续期失败继续使用尚未到期的有效证书并提示；过期或校验失败关闭公网入口。首版只有一个节点，节点描述和传输适配接口用于后续扩展，不提供多节点自动切换。

## Codex 执行

- Codex 会话统一使用电脑上的 `codex app-server`，不再跟随官方桌面应用。打开只建立观察，发送时自动续接；主机仍核对 CLI 最低版本、原生会话身份、工作区和同一 `CODEX_HOME`，实际发送以原生 writer lock 裁决为准。
- 首次订阅取得原子基线，随后通过 Runtime 原生事件流和 SSE 推送文本、工具及状态。正常聊天不定时请求 live 或历史；断线按成功应用游标恢复，缺口或运行实例变化重新同步。发送、停止和审批仍在执行前核对原生归属与 revision。协议与桌面共用逻辑见 [实时会话](../sessions/conversations.md)。
- 「新建 Codex 任务」从已授权工作区创建，支持选择主机已验证的模型与思考强度；创建成功后再发送首条消息。默认是工作区写入、按需审批。完整授权浏览器可以从主机映射的策略中显式切换，但不能提交任意 cwd、命令行、sandbox 或审核器参数；旧浏览器不会因此获得新权限。
- 输入区显示主机实际模型、思考强度、计划模式、服务档位、执行策略、上下文用量和目标。设置仅在空闲时可改，并在原生回读确认后显示生效；执行中不会让用户误以为当前轮次已经切换。托管会话支持目标创建、修改、暂停、恢复和清除，不创建 AgentKib 自动续跑调度器。
- Plan 位于对话设置；选择显示「下一轮」，显式发送后才由原生模式事件确认。Goal 位于添加菜单，更新保留原生状态，启动／恢复单独执行；未确认设置会阻止启动／恢复。预算受限显示「尝试恢复」，不承诺已经继续执行。设置、目标及队列能力以当前 app-server 验证结果为准；按对应域的事件更新，已有编辑草稿保留，双端修改后需重新载入。
- 「添加」区分手机上传与电脑文件／目录、技能、插件和应用引用。浏览器只提交设备绑定的不透明 ID；桌面和 runtime 在发送前重新检查授权、revision、路径范围、符号链接和资源存在性。当前托管协议已验证文件、目录和技能引用；插件与应用没有可靠原生提及路径时会显示不可用。
- 写锁被占用时显示「正在 Codex 中使用」及选择条，可显式「分支会话并继续」或「回 Codex 继续」，不自动分支。保留草稿并定期重新检查；只关窗口可能仍占锁，需要完全退出 Codex 应用。不会自动关闭原客户端或删除锁文件。
- 目录和 live 状态带只读的 `externalTurn`，表示这条会话有一轮正在 Codex 应用或 CLI 里执行，依据是写锁被持有且 rollout 里最新一轮没有结束。桌面、Web 和手机的列表据此显示运行中。它不影响发送、分支或占用判断。
- 每条运行会话使用独立 app-server 进程；一轮结束后空闲约 1 分钟释放自己的进程及写锁。最后一个订阅者离开时，等待当前轮次结束后释放；下次发送自动重新校验和启动，不显示手动恢复入口。未知回执等安全屏障继续保留。
- 未知回执不会自动重发。手机显示未知结果并阻止直接重复管理操作；已有托管任务可核对原生状态。恢复依据持久命令账本及原生请求身份，不能确认时继续保留阻断。
- Codex 发送、停止、审批、问答以及创建/交接使用持久命令回执；浏览器仅在 sessionStorage 保存按主机和设备隔离的请求标识，不保存消息正文。页面刷新后查询原请求，`unknown` 或未找到回执不会因手动刷新、空闲状态而解锁。accepted 仅表示请求被接受，审批是否完成仍看原生状态。
- 停止表示中断当前轮次，不代表所有外部后台进程均已退出。

实现与恢复细节见 [Codex 托管说明](../agents/codex-managed.md)。follower 模块暂时保留但主路由不调用。隔离 native writer-lock 与合成 app-server 测试不替代真实 CLI、桌面/Web 或手机全流程验收。

## 产物、文件和差异

手机会话的「文件与产物」包含三个视图，完整控制的浏览器另有「网页预览」，显示电脑上正在运行的网页（见 [网页预览](../sessions/web-preview.md)）：

- **会话产物**：分页解析会话回复里提到的文件，经主机核实后展示。识别 Markdown 链接的本地目标和行内代码里的文件路径（如 `src/app.py:12`），去掉行列号后缀和开头的 `./`。相对路径先按会话的工作目录查找，再按工作区根目录；会话在隐藏目录（如 `.worktrees/` 下的工作树）或工作区之外运行时不解析相对路径，以免显示另一份检出里的同名文件。不是按最近修改时间猜测，也不会把整个目录自动标成该会话生成。没有文件引用的工具产物可从项目文件浏览；目前不承诺从所有提供方的原生工具载荷自动发现附件。
- **项目文件**：按需浏览授权目录。文件 ID 绑定设备及目录授权，文本读取绑定版本；目录变更、设备撤销使旧票据失效。隐藏文件、已知凭证、原始 agent 日志、链接逃逸与特殊文件受限制。
- **Diff**：只读查看工作区、暂存区和指定提交。项目差异可能包含用户原有修改，不能解释为全部由当前会话生成；不提供远程 commit、push 或回滚。

浏览器可直接预览图片、支持编码的音视频、文本、代码、Markdown、JSON、CSV 和静态 HTML；PDF 提供浏览器打开/下载，其他文件提供下载。没有自动转码、Office 转换或文件云上传。

HTML 以入口所在目录生成明确清单和固定版本快照，默认限制 32 MiB/256 文件，总快照 64 MiB。支持包内相对脚本、样式、图片、字体和 JSON；使用独立 origin 及无 same-origin 权限的沙箱，无法访问主站控制 API。外部 CDN、开发服务器、后端 API、弹窗和 worker 不属于首版支持范围；请将构建 base 设为相对路径。沙箱用于隔离应用权限，不宣称对任意脚本提供绝对断网。

媒体通过原生 GET/HEAD/Range 流播，内存不会按视频总大小分配。票据即将过期时由可信父页面续期，媒体恢复播放位置；文件版本改变则要求重新打开。票据是短效能力 URL，勿分享；绑定设备授权意味着撤销设备后失效，并不意味着已复制 URL 具备额外的接收者身份验证。

## 接口与兼容

现有 `/api/web/v1` 路径保持兼容，增加：

| 接口 | 用途 |
| --- | --- |
| `GET managed/options` | 可用性、模型、主机映射策略、默认值与已授权工作区 |
| `POST managed/create/adopt/release/reconcile` | 管理任务；需要 manage、主机 boot ID 和唯一 request ID |
| `GET files/workspaces` | 文件读取授权根 |
| `GET files/list` | 目录 ID 浏览 |
| `GET files/text` | 文件 ID 与版本读取 |
| `GET artifacts` | 指定会话、工作区和可选 cursor 的文件引用 |
| `GET artifacts/resolve` | 按同样规则解析会话回复里的一个文件引用（`reference`），返回文件条目；找不到或不允许读取时为 null |
| `GET diff` | 授权项目的只读 Git diff |
| `POST artifact-tickets` | 文件或 HTML 包的预览/下载票据 |
| `POST account-binding` | 官方中继验证 PKCE 云登录证明；独立旧主机仍可核对 `sessionId`。返回 `{bound}`，同账号的已验证新登录可续接有效配对，跨账号拒绝；登录证明不授予配对权限 |
| `POST live-preview-tickets` | 电脑上某个回环端口的网页预览票据；只给完整控制 |
| `GET codex/session-settings` | 原生 `current`、下一轮 `selected`、`applicationStatus`、主机默认设置、逐字段写能力、`options.collaborationModes` 与上下文用量；新增字段缺失不推断已支持 |
| `GET codex/goals` | 原生目标、预算、token 消耗、运行时间及可用操作 |
| `GET codex/context-options` | 当前会话可引用的电脑文件／目录、技能、插件和应用候选 |
| `POST codex/settings` | 按 revision 更新下一轮设置或恢复主机默认 |
| `POST codex/goal-*` | 设置、暂停、恢复或清除原生目标；`goal-set.intent` 为 `start`／`update`，预算省略保留、null 清除 |

预览 origin 的 `/p/...` 只处理票据内容，`/live/...` 与 `/live-sw.js` 只处理网页预览，都拒绝控制 API；主 API 继续校验设备、Origin 和 CSRF。`GET access` 的 `pairingMode=code` 表示支持授权码直接连接；缺少字段或为 `confirmation` 时保留旧确认流程。新授权凭证含 `device.accessMode=full`；旧凭证不自动增加此标记或扩大授权。已批准的设备还会拿到 `computerName`，即系统设置里的电脑名称（macOS 读 `scutil --get ComputerName`，Linux 读 PRETTY_HOSTNAME，其他平台用主机名，每 10 分钟重读一次），手机在名称还是连接地址时用它称呼这台电脑，账号里的名称仍然优先；未批准、配对中和已结束的请求都不带这个字段。执行账本与可重建会话索引分开保存。

## 验证边界

预览默认每台电脑合计 2 MiB/s，在高级设置保存后生效。大文件同时最多 8 路、每个配对设备最多 4 路，超额返回 429 与 `Retry-After: 1`；控制与预览的服务端代理另有独立限额。视频仍受主机上行带宽、运营商链路和浏览器编解码支持限制。续票暂时失败会保留仍有效的预览并重试，到期或撤销后停止；续票成功恢复播放位置，文件版本改变则要求重新打开。

## 附件与原生高级操作

新授权码连接的浏览器可在 Codex 输入区选择文件或粘贴图片，托管会话与发送使用同一条件开放，不可用时附件按钮说明原因；旧浏览器仍需原有附件权限。每文件上限 25 MiB、每条消息合计 100 MiB／10 个附件、主机存储上限 2 GiB。未发送草稿 24 小时过期；已发送或结果不明的引用保留，显式删除会影响历史引用。上传文件只保存在电脑私有目录，不自动解压、执行，也不因此扩大 Codex 沙箱范围。图片交给原生图像输入；其他文件以文件引用交给原生任务，能否读取由原生权限决定。

运行中的托管任务可追加指令，或加入官方待发队列；后者会在当前任务完成后自动执行。CLI 没有原生队列时（0.147.0）只能追加指令。会话工具提供按能力开放的重命名、归档、取消归档、永久删除、分支会话及下一轮模型设置；重命名、归档和删除需要整理权限，也在会话列表每行的「会话菜单」里，删除前要确认；上下文用量对话框可以压缩上下文，输入区的 `/` 菜单列出 AgentKib 能代为执行的 Codex 命令，`/stop` 结束后台终端（见 [Codex 托管执行](../agents/codex-managed.md#压缩后台终端与斜杠命令2026-10-28)）。仅有历史读取权限的浏览器不会因此取得这些能力。页面待处理入口集中提示已经收到的审批和问答，包括 MCP 工具审批与 MCP 请求；关闭页面后没有系统推送。失败的轮次以 Codex 的错误文字结束，重试时输入区显示进度。

新接口包括 `GET codex/capabilities`、`GET codex/queue`、`POST codex/<action>` 及 `POST/GET attachments`、`POST attachments/delete`。仍使用现有同源 Cookie、Origin/CSRF 与设备授权，不接受浏览器传入任意原生 RPC 或本地文件路径。断线后的未知写操作先查原请求回执和原生证据，不能通过重命名、恢复或刷新绕过。
