# 会话正文搜索与历史引用

桌面与 Web 可以在当前主机的可读会话中搜索用户、助手文字及可读取的工具输入输出，再把选中的片段加入当前会话草稿。搜索、定位和添加引用不调用模型；只有用户明确发送时，引用才与消息一起交给当前目标 Agent。

## 开启与使用

正文索引默认关闭。由主机所有者在桌面 **设置 → 隐私 → 会话正文搜索** 中选择“启用正文索引”；会话索引总开关也必须开启。Web 浏览器可以使用主机已开启的搜索，但不能开启、清理或重建主机索引。

索引未开启时，桌面搜索窗口中的「前往设置」打开主应用的隐私设置；尚需在该处明确启用开关。Web 显示主机端的设置路径，由主机所有者操作。没有主应用导航的嵌入环境同样保留手动路径。

1. 在桌面全局搜索、会话目录或桌面/Web 会话中的“搜索会话正文”入口输入关键字。可按工作区、Agent、正文/工具及归档状态筛选。
2. 查看命中片段、来源 Agent 与工作区，点击结果定位到对应正文块；定位窗口也显示工作区，需要时读取相邻块。定位不会把整篇历史传到客户端。
3. 在正文块内选取片段，加入“历史引用”。会话内引用保留当前目标和草稿，不切换到来源会话；独立搜索入口可以先阅读来源。
4. 需要进入来源会话时，在命中原文详情点击「打开会话」。会话内跨会话打开前会确认清理未发送的草稿、引用和附件；取消则保留当前内容。确认后重新核对来源和当前访问范围，已失效或不可读的来源不能打开。打开后按该会话正常历史读取流程展示，当前不支持自动跳到命中消息；命中原文仍可在搜索定位窗口中查看。此入口与「引用到当前会话」分别操作。
5. 检查引用卡片下方的完整待发送文本，包含当前草稿、来源与角色标签及全部摘录。编辑草稿或移除引用会同步更新预览，然后明确发送。发送、steer 或加入队列仍受目标 Agent 原有能力、归属及控制权限限制。

搜索范围显示为“仅此主机”。桌面汇总的其他已配对主机会话继续支持标题搜索，不跨主机汇集正文；连接该主机的 Web 时，正文搜索使用该主机的索引与授权范围。独立目录入口在每次打开前重新核对当前范围；工作区登记变化后可直接重新打开，旧结果不会沿用。旧主机未声明搜索能力时不显示此入口。

## 来源覆盖

“支持”表示读取当前可验证格式中的完整可读记录，具体会话仍以界面的来源覆盖状态为准。索引独立读取原始来源，不把历史界面截断后的分页当作全文。

| 来源        | 用户/助手正文                                   | 工具输入与输出                 | 读取与限制                                                                                                                                                                                                                                                                                                                                                                          |
| ----------- | ----------------------------------------------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Codex       | 支持                                            | 支持 function/custom tool 记录 | JSONL；去除消息镜像，保留真实重复消息；损坏正文及尚未支持的工具/响应记录提示部分覆盖                                                                                                                                                                                                                                                                                                |
| Claude Code | 支持                                            | 支持 tool use/result           | JSONL 当前有效分支，并沿 `compact_boundary` 覆盖压缩前的完整谱系（接回候选依次为 `logicalParentUuid` 与保留段头部），按每个压缩边界之前的最近版本接回父链，输出按 UUID 去重，压缩摘要本身不入索引；边界接不回更早历史、回溯途中缺少父记录或耗尽历史回溯总预算时标为部分覆盖并提示 `compaction-link-unavailable`；排除辅助分支与字符串、富文本中的内部命令回显；工具输出保持文本记录 |
| OpenCode    | 支持                                            | 支持可读取的 tool state        | 一次有界原生导出，非逐页重复导出                                                                                                                                                                                                                                                                                                                                                    |
| OpenClaw    | 支持                                            | 支持可读取的 tool call/result  | schema-23 SQLite 有效投影或旧 JSONL；SQLite 确认改属、外部接管或共享作用域后撤回旧索引；旧 JSONL 遇到无法验证的分支/重置/压缩控制时标为部分覆盖，不混入其他分支                                                                                                                                                                                                                     |
| Hermes      | 支持                                            | 支持可读取的 tool calls/result | JSONL 或 SQLite 只读快照，包含已提交 WAL；SQL 归属与正文在同一事务读取；需要关联 JSONL 补全工作区时提示部分覆盖；跳过非活动记录，压缩原文缺失时提示部分覆盖                                                                                                                                                                                                                         |
| Grok Build  | 支持                                            | 支持可读取的 tool calls/result | 本地 JSONL；未支持的 backend tool 记录提示部分覆盖                                                                                                                                                                                                                                                                                                                                  |
| Antigravity | 支持 ACP 返回的正文                             | 支持 ACP 可读取的工具输入输出  | 官方 ACP 历史回放；不能代表其全部 Desktop/IDE 或 CLI 历史；未知消息块使正文显示部分覆盖，未能还原的工具内容使工具显示部分覆盖                                                                                                                                                                                                                                                       |
| Cursor      | 支持可验证的 CLI 存储及已连接 macOS IDE profile | **未支持**                     | 验证本地存储/会话图；工具覆盖明确显示 unsupported                                                                                                                                                                                                                                                                                                                                   |

不解析附件正文、图片、音频或隐藏推理。常见敏感值在写入派生索引前复用现有脱敏规则处理；索引保存的是处理后的文本。辅助/子代理及普通执行记录继续沿用目录隐藏规则，正文搜索不会扩大可见范围。DeepSeek Harness 不在本轮八来源范围内。

脱敏规则版本升级时，旧正文代际及定位符在查询前失效，不能继续返回旧片段；随后从原始来源重新脱敏建立索引，不改写原生历史。查询 Worker 先于索引 Worker 打开旧版本缓存时，也会拒绝读取，等待缓存重建。

索引期间结构化脱敏执行失败或确认原生工作区归属变化时，该来源整体不可用，并清除其派生正文，不继续展示旧缓存。OpenClaw SQLite 的来源身份随已提交正文保存在派生缓存中，刷新时只读核对该来源；重启或临时离线后仍能区分改属与暂时不可读，其他 Agent 数据库异常不会连带撤回它。早期脱敏或归属校验版本建立的派生索引会在初始化时自动失效并重建，不修改原生历史；Claude Code 会话的来源身份包含压缩谱系解析版本（当前为 `claudeLineage:3`），旧版本索引会重建，旧位置失效，其他 Agent 的索引不受影响。正文中的空字符及换行保留，搜索、定位和引用使用同一完整文本；选段会将浏览器换行规范化后的偏移映射回原文，高亮与检索共用字面匹配规则。

来源覆盖区分已完成、构建中、部分覆盖（partial）、旧缓存（stale）与不可用（unavailable）。损坏、缺失必要正文或超限记录不会伪装为完整记录；能安全读取的部分仍可搜索，缺失范围会明确提示。合法的纯工具调用及附件记录保持各自覆盖规则。来源身份、权限或格式无法验证时可能整体不可用。未命中不等于所有原始历史均已检索完成。

整份快照因损坏或超限读取失败时，不会用空结果覆盖此前已提交的安全缓存：已有内容保留并标记旧缓存，首次读取失败则标记不可用，同时记录损坏或超限原因。旧缓存可以搜索，但定位及引用仍需重新验证原生来源；完整读取成功后才更新内容和覆盖状态。

各来源的正文与工具状态分别计算。例如 Cursor 正文完整时显示“正文支持、工具未支持”；仅工具解析受限不会把完整正文标为部分覆盖，反之亦然。损坏、超限或无法区分影响范围的限制仍保守影响两类状态。顶部完成数反映整体来源覆盖，因此工具未支持的来源仍计入整体部分覆盖；每个来源行展示两类状态，不再混用整体完成数。已有缓存按保存的限制原因重新计算，无需重建。

首次建立索引或新增会话时，尚未开始读取的会话也计入对应 Agent 的构建中数量；部分会话已完成不代表该 Agent 全部覆盖。完全尚未索引的 Agent 仍会列出，正文显示暂不可用，Cursor 工具继续标为未支持。索引 Worker 退出后，整体及各来源的待构建数量同步转为不可用，并提示需要重建；已提交的安全缓存保留。所有统计均限于当前获授权的会话。

## 输入、引用与缓存限制

| 项目                 | 当前边界                                                                                                                               |
| -------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 搜索词               | 最多 256 个 Unicode 字符，接口同时限制为 4,096 个 UTF-8 字节；按文本匹配，不区分大小写                                                 |
| 一次草稿中的历史引用 | 最多 5 处，选中正文合计不超过 8 KiB（UTF-8）                                                                                           |
| 最终发送文本         | 用户文字、引用来源标签与片段合计不超过 16,000 个 UTF-16 代码单元且不超过 16,384 个 UTF-8 字节；附件和原生资源仍遵守各自限制            |
| 派生索引预算         | 1 GiB，包含 SQLite/全文索引开销；达到预算后停止新增索引并提示容量限制，可清理或重建。该预算不是 SQLite 临时 WAL 文件的瞬时物理大小保证 |

单个来源还有有界读取限制，例如 JSONL 单行 4 MiB、单次来源扫描 256 MiB/100,000 条；部分原生适配器更严格。界面显示搜索结果受限时，应缩小关键字或筛选范围。

检索与高亮共用按字符的小写规范化，避免希腊字母 `Σ` 因所在词的位置改变而漏检；`Σ`、`σ`、`ς` 视为同一大小写形式。字符展开后的命中仍定位原始正文，引用不会替换或改写原文。规范化规则或运行时字符表变化后，派生索引自动失效并重建。

位置包含来源版本、记录与正文块身份。定位、添加引用和发送前会重新核验来源；原文内容、会话标题等来源说明或身份变化后，旧位置及尚未发送的引用可能失效，需要重新搜索、定位和选择。请求已经接受后，引用随接受的输入冻结；重复请求复用原回执，结果未知时不会自动重放或重新发送。

## 隐私、权限与清理

- 正文索引保存在主机的独立、可重建数据库中，不修改原生历史。索引与查询使用专用 Worker，普通目录刷新会核对完整来源版本；即使会话标题等摘要未变，正文变化也会更新索引，来源未变则保留已提交代际。完成回合或历史失效事件也会触发更新。
- Web 只返回当前浏览器授权工作区及可见会话内的结果；来源可读权限与目标发送权限分别检查。权限撤销或范围变化后，在途读取不能继续返回旧范围内容。
- 移除工作区或变更来源归属会先取消对应可见性，再清理派生记录。其他浏览器授权变化不会扩大主机本地的索引范围。
- 定位或引用核验一旦确认来源改属或脱敏失败，会立即隔离该来源并拒绝在途旧结果，再由索引 Worker 清理缓存；只有完整重新索引成功后才恢复可见。写 Worker 已退出、无法持久清理时，清除可重建的正文缓存，防止重启恢复已拒绝的内容。临时离线不触发此隔离。
- “清理索引”删除派生正文数据库及其 WAL/SHM，保持开关现状；仍启用时，之后的正常刷新可以重新建立索引。“关闭并清理索引”同时停用并删除正文索引。
- 关闭会话索引总开关，或清空会话索引，也会清除派生正文索引。关闭总开关期间不能启用正文索引。上述操作不删除原生会话历史。

## 本轮验证范围

本轮证据来自 TypeScript 自动化：八来源格式 fixture、超过 256 KiB 的正文、Unicode/重复记录、SQLite WAL、来源变化与清除、真实后端 Worker 生命周期，以及桌面/Web/LAN 权限和引用回执测试。新增真实宿主、Router、Backend、搜索 Worker 到合成 Codex/Claude CLI 子进程的用例，检查最终原生输入、实际派发次数和重启回执；它证明协议接线，不能代替真实产品或模型验收。未为此功能调用真实模型，也未在本机执行 Windows/Linux 验收；历史 Rust Runtime、原生 UI 或模型回复记录不作为本功能的 TypeScript 验收证据。
