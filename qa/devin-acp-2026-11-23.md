# Devin 改走 ACP，并可担任项目 Agent（2026-11-23）

## 结论

- Devin CLI 3000.14.30833 的 `devin acp` 使用 `devin auth login` 保存的登录（3000.12.59 时会拒绝）。AgentKib 的 Devin 会话改为每一轮启动一次 `devin acp`：新建用 `session/new`，继续用 `session/load`，模型和权限模式用 `session/set_config_option`，然后 `session/prompt`；这一轮结束后进程退出。
- 权限四档对应 ACP 模式：`accept-edits`→Code，`auto`→Ask（只回答，不改代码），`smart`→Smart，`dangerous`→Bypass。Devin 发来的审批（`session/request_permission`）进入“等待你”，只提供“允许一次”和“拒绝”。
- Devin 会话可设为项目 Agent：每一轮把 `agentkib_workers` 回环端点作为 `mcpServers` 交给 Devin；调用这些工具前的审批自动“允许一次”。汇报经 AgentKib 的 Devin 会话控制发出或排队。
- 旧 CLI 在 ACP 模式拒绝本地登录时报 `devin-cli-update-required`，四种语言说明需要更新 Devin。

## 真机验收（3000.14.30833，模型 swe-2，临时工作区和临时会话目录）

| 场景 | 结果 |
| --- | --- |
| 新建，第一条消息随新建发出 | 通过，得到会话 ID，这一轮正常结束 |
| 继续同一会话 | 通过 |
| `accept-edits` 下运行 shell 命令 | 进入等待审批，选项只有允许一次和拒绝，标题 `Exec(touch)`；拒绝后文件没有创建 |
| 只读（Ask 模式）下要求写文件 | 没有修改，也没有审批 |
| 停止长任务 | `session/cancel` 后约 2 秒结束，结果为 cancelled |
| 项目 Agent 的工具 | Devin 调用了 `agentkib_workers` 的工具，审批自动放行，没有留下待审批 |

另外用探测脚本确认：`session/load` 时同样可以传入 `mcpServers`，加载前会回放历史更新（AgentKib 忽略）；会话的模式和模型在进程之间保留；Devin 在回答 `session/new` 之前就会发出 `available_commands_update`，ACP 客户端现在接受这类更新。

## 本机环境说明

pnpm 12.10.1 的入口在本机无法直接执行，用 `~/Library/pnpm/.tools/pnpm/11.25.0/bin/pnpm`（自动切到 12.10.1），并在 PATH 前放一个转发到它的 `pnpm`，否则 `backend:build` 里的嵌套 `pnpm` 调用失败、后端产物不更新。
