# DeepSeek Harness 二期 2b（图片附件）QA — 2026-11-05

本文记录二期 2b 的源码、自动化结果和真实验收：图片附件做成各 Agent 共用的能力，接入 DeepSeek Harness（DSH），并为跟随 ChatGPT 桌面端的 Codex 会话开放。结论只适用于下列源码与版本。方案见[接入方案](../docs/agents/deepseek-harness.md) §7 的“2b 实现”，2a 记录见[二期 2a QA](dsh-integration-phase2a-2026-11-05.md)。

- DSH 沙箱与 2a 相同：AgentKib 桌面开发版、独立 HOME 与数据目录；DSH 自己的 Web 界面在独立 profile 的无头 Chrome 中操作；手机为 Android 模拟器 `AgentKib_QA_API35`。
- 没有新增生产依赖或持久化结构。插件与 Host 的私有协议改为：发送命令带内容数组（文字与图片），新增按会话读取图片的命令；待发条目带图片数，历史用户消息带图片引用。

## 实现范围

- 通用层（Host）：上传、校验、设备与会话绑定、能力开关（`attachments`）沿用现有附件存储；交给执行者这一步按执行模式查表（`ATTACHMENT_FORMATS`）：Codex 托管与 Codex 跟随按本地路径（`localImage`），Claude 托管内联 base64，DSH 交文件路径、大小与 SHA-256。其他文件对所有执行者都以一行路径说明写进消息。
- DSH：插件读取附件文件、核对摘要后把图片作为 `prompt` 的图片内容交给 DSH，图片字节不经桥接 socket；历史用户消息带 DSH 存储的图片引用，Host 生成 `dsh-image-v1-<摘要>`，经现有 `/session-images` 按会话读取并核对摘要；待发消息带图片或文件时标为有附件，不能编辑。
- Codex 跟随：附件与发送同条件开放。
- 客户端：图片被拒的原因对所有 Agent 显示具体文字（以前只有 Codex 与 Claude 保留原因）；DSH 待发条显示回形针并禁用编辑；经 app-server 发出的 Codex 图片消息不再显示末尾的 `<image …>` 标签。
- Flutter：图片被拒的几种原因有四语文字；DSH 夹具更新为运行中可带图片、待发队列含带附件的条目。

## 发现的问题

1. **图片被拒只显示通用文字**：Host 返回了正确的 409 原因，但桌面与 Web 的控制器只为 Codex 与 Claude 保留未执行原因，DSH 一律显示“本次操作未执行”。已改为对所有 Agent 保留图片被拒的原因并显示对应文字；桌面端在真实 DSH 上复验通过。手机端此前也只显示通用失败，本轮同时补上。
2. **经 app-server 发出的 Codex 图片消息露出标签**：Codex 把 `<image name=[Image #n] path="…">`（结束标签另起一行）追加在正文后，原有的显示过滤只认桌面端界面自己的附件包装。已在显示层识别这种尾部标签（编号恰好对应这条消息的图片且不在代码块内时才隐藏），真实会话复验通过。AgentKib 自己的 Codex 进程发出的图片消息同样受益。
3. **排队消息里的文件说明**：DSH 把文字块拼成一段，文件说明行混在正文里，待发条目因此可编辑，编辑会丢掉文件引用。已把这些行单独列出，条目标为有附件，真实 DSH 上复验通过。

## 观察（非本轮问题）

- 发送进行中时，Web 对 `managed/capabilities`、`managed/settings` 与 `events` 的读取会收到 409 `operation_busy`，客户端随后重读。这是 Host 在控制进行中拒绝读取的既有行为，一期已为待发队列加了重试。
- 从 DSH 自己界面发出的图片消息，合成模型的回显不含输入文字，只有 DSH 附加的图片说明；AgentKib 的显示正常，属于合成模型脚本的取值方式。
- 跟随测试的第二个实例启动时，PATH 上的 codex `0.163.0` 起了一个 app-server，改写了 `~/.codex/skills/.system`（已知现象，用户当前的 Codex 下次启动会恢复）；它没有持有任何会话的写锁。停止该实例后这个 app-server 没有随之退出，后来已不在运行。
- 手机上选中 9000×2 的超宽图片后，输入区出现过一次通用的“The request could not be completed. Try refreshing”，同一时段代理没有失败请求，上传本身成功；原因未查明，疑似客户端对超宽图片的预览处理，与 Agent 无关，留待单独排查。
- 手机配对后 `GET /read-state` 返回 404 `read_state_unsupported`，为既有行为。

## 已知限制

- 手机对所有 Agent 都只显示“📎 N”，没有历史图片缩略图。
- Claude 终端连接的提交接口只接受文本，不提供图片。
- 模型是否收图片由 DSH 在发送时判断，AgentKib 不预先读取模型的输入模态；没有运行的 DSH 时历史图片显示不可用。
