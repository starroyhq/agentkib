## 持续采样

执行 `node apps/desktop/scripts/benchmark-energy.mjs 10 output/energy-benchmark-2026-09-09.json`，预热 40 秒后，前台与隐藏实例分别记录 121 个样本、600.04 秒。原始结果保存在本地 `output/energy-benchmark-2026-09-09.json`，不纳入提交。首轮实例提前退出，没有完整记录，不计为通过。

| 指标 | 前台 | 后台 |
| --- | ---: | ---: |
| 发现刷新 / 统计刷新 / 远程状态查询 | 0 / 0 / 0 | 0 / 0 / 0 |
| CPU 累计时间（整个被采样进程组） | 1.668 秒 | 1.482 秒 |
| 平均 CPU（单核 100%） | 0.278% | 0.247% |
| 磁盘读取 | 4,096 字节 | 167,936 字节 |
| 磁盘写入 | 5,541,888 字节 | 5,259,264 字节 |
| 每个样本中的进程数 | 5 | 5 |

每组包含 Electron 主进程、GPU、Utility、renderer 和 Runtime。记录中前台有 30 次 `runtime.info`、10 次 `gateways.list`，后台各 10 次；它们读取本地小配置，未联网或扫描日志。后台连预热阶段也未启动发现/统计；前台预热期间各执行一次初始化。

CPU 使用 `proc_pid_rusage` 累计时间，按本机 Mach timebase 125/3 转换为纳秒，原始 ticks 保留。磁盘数值是系统记录的进程物理 I/O，不等同于逻辑文件读取量；包含采样结果逐次落盘的写入开销。采样用 Python 辅助读取进程资源，辅助进程不在上述五个常驻进程中。

使用独立临时数据和 Electron 配置，额度关闭、Codex Home 为空；未改变安装版配置。采样验证空闲调度，最终逐来源检查点和在线心跳去重另有针对性测试与后续构建验证。它不覆盖额度网络活动、活跃远程会话或真实大历史库的整机功耗，也不是优化前后对照，不能据此承诺 macOS 高能耗提示必然消失。
