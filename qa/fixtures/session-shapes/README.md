# 会话形状夹具

`claude-handover-settings.mjs` 在全新的临时沙盒中生成一条已接管的 Claude Code 会话。录制中的 ID、目录、账号和文本均由夹具自行生成或使用固定测试文案。它也会生成约 4.8 MB 的 JSONL 转录，包含完整的末轮父链和尾部元数据。

待核对的快照为 `outcome-unknown`，末轮在转录中有成功证据。账本有三条已结算的设置回执、一条已结算的发送回执，以及一条在途设置回执。同一会话还保留一个没有活动租约的桥接绑定、空宿主队列和一个合成账号的已读游标。目录由测试环境创建自己的工作区和会话。

行为基线和桌面真包回放共用 `seedClaudeHandoverSettings`。调用端先创建并注册临时工作区，然后在运行时停止期间写入夹具。临时数据目录、Claude 配置目录和工作区必须在同一个沙盒中。函数返回会话、末轮及在途设置回执的合成 ID，便于断言核对期间没有重派。
