# PR #66 评论、Windows 与依赖安全修复

## 证据与修复

- 评论 `3967198619`：SSE 将 `ServerResponse.write(false)` 误判为失败。改为等待 drain 后恢复轮询，已缓冲帧不重放；close/finish 清理计时器与监听器，持续堵塞 30 秒后释放连接。补模拟背压、撤销/关闭/超时和真实 HTTP 1 MiB 快照回归。
- Windows run `34338094344`：Insights 9 项失败。混合路径分隔符在原始字节哈希下不一致，使 SQLite 与 JSONL 归属不匹配；统一来源路径组件，parser version 2 触发旧 checkpoint 重建。不使用需要文件存在的 canonicalize。文件时间测试使用可写句柄，修复 Windows PermissionDenied。
- Dependabot #2–7：传递依赖 fast-uri 3.1.5 → 3.1.6、qs 6.15.3 → 6.16.0。
- `pnpm audit` 另发现 js-yaml 与 hono 告警，分别升级 4.3.1 → 4.3.2、4.13.3 → 4.13.5。仅对受影响范围设置安全版本 overrides，未升级其他直接依赖。
