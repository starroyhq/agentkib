# 远程连接页改版 R 批（2026-11-11）

依据：本地设计稿 R-1～R-4（`designs/agentkib-remote-previews/`）和 11-09 定下的 R1～R5。分支 `remote-revision-r`，基于 `origin/main`（970698315），和首页改版无关，可以单独合并。

## 改了什么

### 一页两块（R1）

“设置 › 远程连接”不再分“手机 | 其他电脑”两个标签，两张卡片上下排，最下面一行“高级设置”。

- **手机**卡片：第一次进来只有说明和“连接手机”。设置好以后，标题旁写状态（已开启、已暂停、正在连接、连接中断），下面一行写设备数和本月中继用量，用到 80% 起变成提醒色，用完时写明局域网直连和这台电脑上的任务不受影响。右上角是“连接新手机”（暂停时换成“恢复”）和“…”菜单：暂停远程访问、账号、高级设置。下面是已授权浏览器，每台一行，可以改档位、撤销。
- **其他电脑**卡片：“共享这台电脑”开关；开着时显示配对码（两组四位、几点前有效、重新生成）、对方怎么用它，和本机名称（点铅笔改，失去焦点或回车保存）。下面是“已连接的电脑”和“添加电脑”。

### 连接手机（R2、R3）

“连接手机”打开引导窗口，一次只显示当前这一步，标题旁三个点表示走到哪一步：

1. 没登录：先在浏览器中登录。底部“只在同一 Wi-Fi 下用？不用登录”。
2. 登录后自动开启远程访问（登记电脑、准备安全连接、连接），不用再点“开启”。可以关掉窗口，准备好后再来。
3. 二维码和授权码放在一起，旁边选这台手机能做什么（完整控制或只读），默认完整控制。打开窗口时自动生成一个授权码；换档位会换成那个档位的码。过期后点“重新生成”，不自动换。
4. 手机用授权码连上后，窗口显示“某某已连接”和它的档位，可以“再连一台”。

没能开启时，窗口写明原因和下次自动重试的时间，技术细节在“连接诊断”里，可以“现在重试”。

**同一 Wi-Fi**：先说明连接不加密，选用哪个网络，勾选“我了解连接不加密”后“开启并显示二维码”。开启后显示二维码、局域网地址、配对码，以及待这台电脑确认的浏览器。局域网直连开着时，页面最上面的明文提示里有“管理”，打开原来的局域网直连设置（关闭、权限、已授权的浏览器）。

### 高级设置（R4）

单独的窗口，只有一个“保存”和“取消”：

- 连接服务：官方或自建。选自建才出现服务地址、按需的邀请码、frpc 程序和预览带宽。
- 共用的局域网网卡和手机局域网端口。
- “更多设置”收起，里面是本机 Web 服务（启用、端口、外部地址、旧版浏览器的权限、工作区、额外只读目录）；官方服务的 frpc 程序和预览带宽也在这里。
- 保存先存本机 Web 服务和网络设置，成功后再应用连接服务；换了连接服务（包括迁移旧官方地址）照旧先确认，因为会清除浏览器授权。
- 取消或关闭窗口丢弃窗口里没保存的修改。
- 字段多时只滚动字段，“取消”“保存”一直在窗口底部。

### 共享这台电脑和添加电脑（R5）

- 第一次打开共享时，如果还没选过网卡，在原处选“用哪个网络共享”，点“开始共享”。这个选择和手机局域网直连共用，以后在高级设置里改。原来要先去高级设置选网卡并保存，开关才能打开。
- “添加电脑”窗口（会话页的“连接其他电脑”打开同一个窗口）：打开就查找同一网络里开了共享的电脑，点“配对”后输入对方显示的配对码，8 位输满自动提交，不用再点按钮。找不到时说明对方要做什么，可以重新查找或“输入地址”。

## 与设计不一致的地方

1. **有三种情况不会自动开启远程访问**：迁移旧官方地址、设备被撤销后的重新登记、自建服务需要邀请码。这几种会改变这台电脑的登记或清除授权，窗口里要明确点一次（按钮写“确认迁移”“用当前账号重新登记”“开启远程访问”）。
2. **窗口开着时在别处暂停了远程访问，窗口不会自动恢复**，改为显示“开启远程访问”按钮。只有打开窗口时远程访问是关着的，才自动开启一次。
3. **“连接新手机”在没连上时也能点**：打开后显示正在连接、出错原因或需要重新登记，而不是一个点不了的按钮。
4. **其他电脑卡片多了两块**：配对申请（核对校验数字后批准或拒绝）和“可以查看这台电脑的电脑”（可撤销）。这是现有的授权流程，设计没画。
5. **添加电脑多了一步**：配对码提交后，对方电脑还要核对校验数字并批准，窗口显示“等待对方电脑确认授权”和校验数字。
6. **Wi-Fi 二维码下面多了配对码和待确认的浏览器**：局域网直连的浏览器仍要在这台电脑上确认并逐项授权（原有流程）。
7. **高级设置多了“更多设置”**：本机 Web 服务的全部选项放在这里，收起；设计里官方服务只显示网卡和端口，所以官方的 frpc 程序和预览带宽也收在这里。
8. **旧版浏览器的逐项授权申请**仍显示在手机卡片里（只在用旧确认方式配对时出现）。
9. **高级设置的“本机 Web 服务”不再显示“点‘保存设置’后生效”的提示**：窗口自己的“保存”已经说明了；局域网直连设置里仍有这句。

## 一并删除的代码

- “手机 | 其他电脑”两个标签和 `WebAccessSettings` 的 `phoneVisible` 属性。
- 手机的四步引导（`SetupStep`）和单独的“连接新手机”窗口，并入连接手机窗口。
- 页面上可折叠的高级设置，以及其中分开的“应用连接设置”“保存设置”两个按钮，并成窗口里的一个“保存”。
- 其他电脑页面上的“附近的电脑”列表、手动配对表单和空状态卡片；配对只在“添加电脑”窗口里做。

## 验证

- 测试：`src/features/remote` 下 16 个文件 353 项全部通过，保存竞争的 3 项也通过。保存竞争测试里，高级设置是模态窗口，保存进行中打不开局域网设置；局域网设置的保存进行中时，页面上的“管理”“连接手机”、改名、共享开关和高级设置里的“保存”、端口、网卡都锁住；没存成功的网卡不会被拿来开共享，打开共享会先让人选网卡，重新保存成功后才直接使用。
  - 改写的五个测试文件（`WebAccessSettings.test.tsx`、`WebAccessSettings.v15.test.tsx`、`RemoteConnectionPanel.test.tsx`、`RemoteSettingsIntegration.test.tsx`，和用真实 Web 服务测保存竞争的 `apps/desktop/test/remote-settings-save-race.test.ts`）按新界面找按钮，原来保护的行为（发了什么请求、没发什么、草稿保留或丢弃、互斥锁、错误提示、四种语言）都保留。改了范围的是标签、四步引导、页面上的配对表单这些已经去掉的界面；草稿相关的几项改成“取消即丢弃、保存一次提交”。只删了一个参数用例：局域网设置里地址为空的情况，现在只有局域网直连开着时才能打开那个设置，这种情况进不去了。
  - 新增：8 位配对码输满自动提交、少于 8 位不提交；没选过网卡时先存网卡再开共享、存失败不开共享；取消高级设置丢弃网络草稿；配对时对方电脑消失不丢已输入的数字；断开和移除电脑；迁移和换服务先确认；设备被撤销时不自动发送、不当作普通重试，只能点“用当前账号重新登记”；窗口开着时被暂停不自动恢复；授权码过期不自动换新。
  - 后两项和迁移确认是改写测试时发现的问题，修了源码。把旧行为放回去时，对应的测试会失败。
  - 文案测试把新文案文件也纳入检查：四种语言键一致、占位符一致、不出现已淘汰的说法。

### CI

本地跑了 CI 的全部检查：全量格式检查、lint、发布脚本、三端类型检查、Web 和桌面构建、Web 托管版构建、Web 测试（86 个文件 1796 项），全部通过。桌面测试第一次跑有 3 项失败，都在 `remote-settings-save-race.test.ts`，它还按旧页面找按钮；改写后重跑格式检查、lint、桌面类型检查和全部桌面测试，520 个文件 10131 项通过，3 项跳过。

## 没验证到的

- **真实的官方服务和账号**：没有登录真实账号、登记电脑或连真实手机，这部分只有测试和替换返回值的截图。
- **真实的局域网监听和两台电脑配对**：会在这台电脑的真实网卡上开端口，沙盒里没有做。
- **英文、日文界面和深色模式**：只看了简体中文浅色的截图，其他语言由测试覆盖文案。
