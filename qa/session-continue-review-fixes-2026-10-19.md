# 会话无感续接：审查后修复

日期：2026-10-19。基线：`1d9b6176d`。用户审阅审查结论后要求修复；第 5 条（列表状态）由用户选择"不补后台检查，改设计稿"。本轮未提交、未推送。

## 修改

1. **已连接终端不能从这里发消息时**（生产插件 `SEND_CONTRACT_EXPERIMENT=false`）：
   - 后端终端连接的 live 增加 `terminalSend`，即插件的静态发送能力。
   - 状态显示新增 `terminal-watch`：终端已连接，但既不能发送（`terminalSend`），当前也没有 `sendEnabled`。
   - 输入区换成一行"在终端中继续这条会话，这里会同步显示"，终端运行中保留"停止"。
   - 横幅不再重复 `claude-follower-send-unverified`。
   - 插件能发送时，原输入框和"审批和提问在终端中处理"照旧。
   - 会话页（桌面、Web）和工作区 Claude 面板同步修改。
2. **选择条去掉"安装连接插件，以后自动连接"**：连上也发不了消息，留着会把人带进死路。"连接终端"的入口留在"会话操作"。共用组件的 `pluginAction` 保留并注明使用前提。
3. **"回 {Agent} 继续"之后**：只显示一句只读说明（Codex 另加完全退出的说明），不再加载或提供续接命令。复制续接命令只留给平台或版本不支持的"仅可查看"。桌面端的说明不再写"在运行 AgentKib 的电脑上"。
4. **Claude 原因文案**：`claude-cli-unavailable`、`claude-owner-check-unavailable` 补上四语文案，两端相同。
5. **列表和侧栏不显示"正在 {Agent} 中使用"**：原先只在 5 秒内的观测上闪现。现在只显示在 AgentKib 中运行、终端、仅可查看，占用在打开会话后确认。
6. **占用检查**：
   - 排除 AgentKib 自有 worker 所在的整个进程组，`ps` 增加 `pgid` 列。改前，Volta 一类启动器另起的 CLI 子进程会被当成外部占用。
   - 每个巡检周期只观测一次（`agents --json`、`ps`、登记文件），所有 worker 共用。启动前的检查仍每次重新观测，不缓存。
   - 登记类型 `bg` 视为后台会话。
7. **其他**：
   - 简体分支说明改用中文引号“”。
   - "停止"统一为描边按钮，和设计稿 4-2 一致。
   - Web 页头的状态在手机宽度下不再断行。

内部锁、指纹、版本、平台、权限及未知回执校验未改动。跨 Agent 继续、`handoff.*`、Codex follower 也未改动。
