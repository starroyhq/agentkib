## 修改与回归

1. **继续命令**：所有入口仍使用 `ClaudeManagedReadOwner.resumeCommand`。生成器接收可省略的配置路径，只有受控环境显式设置有效 `CLAUDE_CONFIG_DIR` 时才生成赋值；显式路径即使等于默认目录也保留。原工作目录、配置目录、原生身份及前后两次核验均保留，配置覆盖模式纳入稳定性比对。补默认/空白环境、显式配置、POSIX 引号与实际离线执行、PowerShell 引号、读取无副作用的回归。先补测试观察到旧默认命令问题，再修复；相关桌面 5 文件 215 项通过。
2. **清除确认**：桌面/Web 的 `claude-connection-copy.ts` 四语镜像同步，明确“终端继续时不会自动连接，需新连接码”，仅改文案，保留原确认、撤销和持久回执。对应四语及镜像测试通过，Web 针对性 21 项通过。
3. **手机标签**：暂停灰字改为“手机暂时连不上”。依据已保存的规范化官方服务地址决定登录前置，不受未应用草稿影响；自建服务不增加账号要求。保留唯一账号组件及原挂载位置，让原账号行的登录成为唯一可用主操作，避免移动或复制账号控制器而丢失登录/取消保护。已开启状态点、标题、灰字与暂停同一行；连接诊断仅在中断/失败时出现，证书安全提示不隐藏。浏览器档位不重复显示，旧版逐项授权仍保留。新手机弹窗去掉重复档位说明；切到另一档位会隐藏旧档位的码，必须明确生成新码，不自动请求或更改权限。先补红测后实现；旧设置、v15、账号组合 97 项通过，另术语 18 项和真实后端保存竞态 3 项通过。
4. **名称独立保存**：失焦或非 IME 的 Enter 提交，trim 后校验 1～64 字符；使用 store 最新共享状态与地址，成功提示 2 秒，失败保留草稿并提供明确重试。即时锁阻挡 Enter/blur 重复、失焦后同批点击共享开关/高级保存/本机 Web 保存，不串行补发过时的另一配置；原 store 保护过时回读，组件卸载后不改界面状态。高级保存不再处理名称。四语“查找”使用局部字典，不改无关页面。先补 10 项红测后修复；panel 38 + 实际父设置集成 12 = 50 项通过，覆盖失败、刷新、在途、卸载、IME 与同批事件。
5. **技术术语例外**：Web `NativeScope` 读取 `networkApprovalContext.host`，展示如 `https://destination.example.test` 的权限目的地；不是 AgentKib 所在电脑，按设计允许保留四语“主机/主機/Host/ホスト”。新增四语渲染回归，相关 6 项通过，未替换协议字段、域名或用户内容。

## 示例继续命令

以下都是示例路径和会话 ID，不含凭据。默认配置：

```sh
cd -- '/Users/demo/workspace' && claude --resume '00000000-0000-4000-8000-000000000001'
```

显式自定义配置：

```sh
cd -- '/Users/demo/workspace' && CLAUDE_CONFIG_DIR='/Users/demo/Claude config' claude --resume '00000000-0000-4000-8000-000000000001'
```

Windows 默认配置：

```powershell
try { Set-Location -LiteralPath 'C:\Users\demo\workspace' -ErrorAction Stop; & claude --resume '00000000-0000-4000-8000-000000000001' } catch { Write-Error $_ }
```

Windows 显式自定义配置：

```powershell
try { Set-Location -LiteralPath 'C:\Users\demo\workspace' -ErrorAction Stop; $env:CLAUDE_CONFIG_DIR = 'C:\Users\demo\Claude config'; & claude --resume '00000000-0000-4000-8000-000000000001' } catch { Write-Error $_ }
```

POSIX 已用合成离线 CLI 实际验证参数和含引号路径；PowerShell 仅验证生成字符串，未原生执行。命令不清除用户粘贴终端自身的环境变量。
