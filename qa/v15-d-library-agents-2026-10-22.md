## 实施与验证结果

### 技能

- 初始目的地在库、原生清单和部署清单成功返回后确定，空库有使用位置时默认打开使用位置；显式链接、手动选择和后续刷新优先，无参数导航及浏览器前进/后退不沿用错误的临时选择
- 默认目的地尚未查完时显示加载状态，失败不当作空库；发现输入、URL 检查和筛选状态不通过重挂载清空
- 导入按钮数量与导入对话框共用物理位置分组及可读资格，排除 AgentKib 所有目录、活动部署和不可读入口，保留外部别名的原始观察身份
- 同步设置与记录在更多中；空库集中提供计数导入和精选链接，使用位置只展示一次只读说明，卡片“查看”“加入技能库”均为次要按钮
- 其他入口使用既有 Collapsible 组件，默认收起，可用鼠标与 Enter 操作；原始路径始终保存在 title，所有打开、导入和同步仍传完整路径或观察 ID

### MCP

- 默认聚合全局和已登记本机项目，项目继承的全局定义不重复计算；远程工作区不作为本机路径读取或写入
- 行身份为作用域加服务 ID，同 ID 服务的单项、批量、策略和逐 Agent 操作均使用准确来源与修订号，不把“全部作用域”作为后端写入目标
- 全部视图添加、导入、内置工具及官方目录安装/更新前先选择明确的目标作用域；切换作用域或取消后，旧异步检查不继续写入
- 工具栏只有添加、导入和更多，原大作用域卡移除；启用开关与 Agent 分配分离，逐 Agent 入口是“行末更多 → 选择 Agent…”，不能取消最后一个 Agent 代替停用
- 选择 Agent 弹窗关闭后焦点返回原行更多，原行消失时回搜索框；作用域读取失败显示错误和重试，不误报为空
- 空作用域只保留一个添加主操作，并说明其他作用域数量；高级默认收起，运行实例显示准确归属，不为归属未知或已移除项目提供操作

### Agent、导航与路径

- Agent 图标入口移除，进入“设置 → Agent 与集成 → Agent”；额度、洞察仍是两页
- 新设置导航进入 Agent，原无 target 或 MCP/网关/Obsidian 深链接进入集成，旧 `/agents?agent=…&agentFilter=…` 映射到独立的 `settingsAgent`/`settingsAgentFilter`，不会带入工作区选中的 Agent
- 列表区分已安装/未安装，首次来源完成后选择首个有实际数据的 Agent；失败重试不提前锁定默认，显式链接和用户选择不被晚到的数据覆盖
- 页头只显示一次配置目录，能力来自 Runtime 的实际 support；无工作区给出下一步，不画零数值、空用量或空全局配置卡
- 保留源读取失败、重试、警告、版本、远程连接详情和 DeepSeek 的测试版/只读说明
- 新只读 IPC 仅返回主进程主目录，沿用可信 renderer 校验，不接受文件路径、不读 Agent 配置、不增加后端协议字段。无法读取时展示原路径；本机目录边界、Windows 路径及 Unicode 中段省略有单测
- 导航快捷键为首页 1、工作区 2、会话 3、资源库 4、额度 5、洞察 6；前端、原生菜单、帮助和文档同步，设置及前后历史快捷键仍保留
