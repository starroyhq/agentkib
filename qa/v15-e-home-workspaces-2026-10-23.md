## 实施结果

- 首页按新用户、引导中、日常三态排版；摘要与待处理总数一致，日常没有主按钮，最近工作区按需关注优先排序，移除最近活动。
- 首页、列表和页头共用状态计算：诊断错误数 + 警告数 + 本工作区待审记忆数，不计信息项。诊断失败或未完成不再伪造问题或沿用旧的“正常”；诊断详情成功/失败同步摘要缓存。
- 工作区列表全宽，移除右侧详情，行直接打开概览；保留搜索、Agent、状态三类筛选及空间视图、收藏、更多菜单和忽略确认。
- 概览优先显示真实诊断问题及时间，合并资产摘要，增加最近会话；页头路径缩写并保留完整复制，无草稿时隐藏审查入口。
- 首页、概览、工作区会话列表直达统一会话页；复用会话行、原生别名与托管会话目录，目标被视图筛选排除时仅放宽冲突筛选。更多菜单保留原跨 Agent 继续流程。
- 修复真实路由中首次恢复工作区会丢失会话/交接查询参数的问题；交接对话框保存来源，异步刷新目录后仍可完成原预览流程。
- 未安装或未配置的 Agent 来源保持中性；真正的来源读取失败保留错误与重试。四语文案和术语文档同步。

复现时先构建当前工作树的 desktop renderer、Electron/backend、Cursor bridge 和 Web，再依次执行（每阶段切换前关闭验收应用）：

```sh
node qa/probes/v15-e-sandbox.mjs prepare --root /tmp/agentkib-v15-e-example
node qa/probes/v15-e-sandbox.mjs launch-config --root /tmp/agentkib-v15-e-example
# 使用返回的沙盒启动配置检查新用户首页，然后关闭应用
node qa/probes/v15-e-sandbox.mjs discover --root /tmp/agentkib-v15-e-example
# 重开应用检查引导，打开诊断后关闭应用
node qa/probes/v15-e-sandbox.mjs daily --root /tmp/agentkib-v15-e-example
```

`prepare` 只接受新的专有临时目录；每个数据阶段只执行一次。启动配置含本机私有路径，应留在本地，不复制到记录或提交。该脚本依赖 macOS Seatbelt；本次没有验证其他系统的原生窗口布局。

## 与设计的差异及保留功能

- 使用现有跨平台菜单文案“在文件管理器中打开”，对应设计的“在 Finder 中显示”；目录动作保持不变。
- Agent 资产折叠行继续列出原有未配置 Agent 项，展开后仍可查看原明细；没有因设计简化而删掉这些入口。
- 最近会话保留真实来源错误及重试；英文和日文的次要路径/来源使用省略号，名称及操作完整。
- 图标栏保持现有 6 项，诊断和变更计划页保持原功能，未做 E2。

设计稿没有展开的现有功能，按共同约束保留：引导关闭、索引启用/加载/空态/重试、刷新发现、工作区页头应用选择器/复制/重扫、Obsidian 集成和扫描警告、有草稿时的审查/丢弃、待应用计划及交接恢复提示、会话筛选/搜索/归档/无历史内容视图，以及“连接 Cursor 窗口”。用户已在 E 收尾中确认：本批均继续保留在现有位置。
